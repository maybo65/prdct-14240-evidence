Description
Kimi Code CLI (often shortened to Kimi CLI) is a terminal-based AI agent from Moonshot AI that reads local codebases, executes shell commands, fetches web pages, and autonomously plans multi-step solutions for software-development tasks. It calls Moonshot’s Kimi large-language-model family (and can be configured for OpenAI, Anthropic, etc.) to turn natural-language prompts into executable actions, giving developers ChatGPT-like assistance entirely from the command line. See the project repository and official docs: https://github.com/MoonshotAI/kimi-cli ; https://www.kimi.ai/help/kimi-code/cli-getting-started .
